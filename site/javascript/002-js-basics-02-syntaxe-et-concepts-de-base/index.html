Comment ajouter du JS dans une page web?

Quels sont les ingrédients pour écrire du JS ? La première chose dont tu as besoin est une page HTML. Ouvre ton IDE préféré et crée un nouveau document HTML. À la fin de ce document, juste avant de fermer le tag </body>, ajoutes un tag <script>
