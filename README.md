# Archives Wild Code School

Archive personnelle des cours suivis à la Wild Code School (plateforme Odyssey),
constituée avant la fermeture de celle-ci.

## Contenu

- **146 quêtes** archivées, avec leur Markdown d'origine intact
- **442 images** téléchargées et renommées lisiblement
- Un **site statique** consultable hors ligne, avec recherche plein texte

## Consulter

Ouvrir `site/index.html` dans un navigateur. Aucune connexion Internet requise :
le site ne dépend plus d'`odyssey.wildcodeschool.com` ni d'aucun service externe.

## Reconstruire ou mettre à jour

```bash
npm ci --ignore-scripts
npm start                        # extrait ce qui manque, puis régénère le site
npm start -- --site-seulement    # régénère le site sans rien retélécharger
```

Le mode d'emploi complet est dans [LISEZMOI.md](LISEZMOI.md).

## Usage

Copie personnelle de contenus pédagogiques auxquels mon compte étudiant avait
normalement accès, conservée à des fins de révision privée. Ce dépôt est privé
et n'a pas vocation à être rendu public : les cours restent la propriété de leurs
auteurs.
